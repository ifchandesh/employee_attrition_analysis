# Employee Attrition Analysis

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/ifchandesh/employee_attrition_analysis/blob/main/employee_attrition_analysis.ipynb)

A clean and simple project to analyze and predict employee turnover using the IBM HR Analytics dataset, built to run directly in Google Colab.

---

## Project Overview

- **Dataset**: IBM HR Analytics Employee Attrition dataset (1,470 records).
- **Factors Analyzed**: Age, Monthly Income, Department, Overtime, and Job Satisfaction.
- **Classification Algorithms**: Logistic Regression, Decision Tree, and Random Forest.
- **HR Dashboard**: Interactive dashboard displaying key KPIs (Headcount, Attrition Rate, Average Salary) and a flight risk predictor for individual employee profiles.

---

## How to Run in Google Colab

1. Open [employee_attrition_analysis.ipynb](employee_attrition_analysis.ipynb) in Google Colab.
2. Click **Runtime** -> **Run all** (`Ctrl + F9`).
3. The notebook will load the dataset, display the visualizations, train the models, and launch the interactive Gradio dashboard inline.
